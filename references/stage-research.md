# research 단계, 사실과 세계관 자료

> **묻기와 기록.** 이 문서에서 사용자에게 묻는 자리와 원장에 `gate:`·`waiver:` 줄을 남기는 일은 지휘(`<스킬>/SKILL.md`)가 한다. 서브 에이전트로 실행 중이면 그 자리에서 작업을 저장하고 `need_user`로 돌아간다. 서브 에이전트 없이(Codex 등) 이 문서를 직접 수행할 때는 직접 묻고 기록한다. `stage:`·`note:` 줄은 단계를 수행한 쪽이 쓴다.

소설은 사실로 짓는 거짓말이다. 병명, 기관 절차, 공간 구조 같은 디테일이 어긋나면 독자는 바로 이탈한다. 목표는 본문에서 BLACK이 묘사할 모든 사실 디테일에 출처를 붙일 수 있게 만드는 것, 그리고 허구 설정이 자기 발로 서도록 빈자리를 채우는 것이다.

규약은 `<스킬>/references/workflow.md`, 작품 값은 `book-toc.md` 블록을 따른다.

## 0. 게이트와 준비

1. 원장 `02_draft/<run>/00_RUN_STATUS.md`에 `stage: storyline done`이 있는지 확인한다. 이 줄은 사용자가 통과 게이트에서 (a)를 골랐거나, 라운드 상한 게이트에서 (c)를 고르고 `open_red` waiver를 승인했을 때만 생긴다. 없으면 "storyline 단계를 먼저 끝내 주세요"라고 알리고 종료한다.
2. 블록에서 `base_year`, `chapters`, `characters`, 그리고 book-toc의 "명시 금지 항목"을 확인한다. 명시 금지 항목은 조사하더라도 본문에 풀지 않는다.
3. 통과본 `01_test/<run>/storyline.md`를 끝까지 읽는다. 이것이 1차 사실 소스이고, 노트는 그것을 보강한다.
4. 한 줄로 알린다: `입력: 01_test/<run>/storyline.md / 출력: 02_draft/<run>/01_research-notes.md`.

## 1. 이어하기

| 상태 | 동작 |
|---|---|
| 노트 없음 | 처음부터 |
| 노트 있음, 완료 기준 미달 | 빠진 범주만 이어 쓴다 (기존 섹션 덮어쓰기 금지) |
| 원장에 `stage: research done` | "write 단계로 진행하세요" 안내 후 종료 |

## 2. 조사 범주 정하기

storyline의 디테일에서 범주 5~7개를 새로 짠다. 범주 이름은 작품마다 다르고, 다음 다섯 원칙만 고정이다.

1. 작품 안의 사실 디테일을 남김없이 나눌 수 있는 5~7개 범주
2. 범주마다 우선 출처 유형(공식, 학술, 매체, 인터뷰, 사진)을 적는다
3. SF·역사물처럼 현실 사실과 허구 설정이 섞이면 두 영역을 나눈다
4. 인물 직군 범주는 `characters`의 직업에 맞춰 짠다
5. 분위기·감각 범주는 작품의 계절, 도시, 실내외에 맞춰 짠다

장르별 출발점:

- SF: 공간 / 기술·과학 / 제도·정책 / SF 설정의 현실 근거 / 인물 직군 / 분위기·감각
- 가족 드라마: 공간(집·동네) / 가족 관계 자료 / 인물 직군 / 분위기·감각 / 시기 / 사회적 배경
- 역사물: 시대 배경 / 인물 직군 / 공간 / 언어·생활 디테일 / 정치·경제 / 분위기·감각

예시(가상의 근미래 SF 단편): A.공간(오래된 공동주택, 주민센터) / B.작품의 핵심 기술 / C.그 기술을 둘러싼 제도와 동의 절차 / D.설정 연도의 현실 근거 / E.주인공 직군 / F.계절과 날씨.

범주와 핵심 사실을 노트 첫머리 "조사 범위" 표로 먼저 적고 시작한다.

## 3. 검색

- 범주마다 2~3회, 한국어 먼저, 영문으로 확장. 같은 결과만 나오면 키워드를 바꿔 한 번 더.
- 쿼리 패턴: `<디테일> 절차`, `<기관> <공간> 구조`, `<직군> 일상 도구`, `<도시> <계절> 풍경`.
- 범주 충분 판정: 본문에 옮길 사실이 그 범주에서 2개 이상 나올 때.

### 출처 등급

| 등급 | 종류 | 처리 |
|---|---|---|
| [1차] | 공식 문서, 학술 논문, 정부 통계, 1차 인터뷰 | 본문 사실의 근거로 쓴다 |
| [2차] | 공인 매체, 직군 인터뷰, 출판 에세이 | 쓸 수 있다. 1차와 교차 확인 |
| [3차] | 개인 블로그, 커뮤니티, AI 요약 | 단서로만. 본문 근거 금지 |

충돌 처리: 1차끼리면 최신·신뢰도 높은 쪽을 채택하고 둘 다 메모한다. 1차와 2차면 1차. 2차끼리면 둘 다 적고 "본문에서는 모호하게 둠".

## 4. 출력 형식

```
# 리서치 노트
## 메타
- 조사일 / 작품(블록 title) / 기준 연도(블록 base_year, 현실 사실은 조사 연도)
## 조사 범위 (범주 표)
## A. <범주>
### <디테일>
- [1차] 출처: <URL 또는 문서명>, 게시일
- 사실: …
- 해설: …            (추론은 '해설'로 분리)
- 본문 활용 위치: <장>
(범주 반복)
## 현실 사실 / 허구 설정 경계   (해당 작품만)
## 미해결 항목
```

- 숫자는 단위와 출처를 붙인다. 긴 인용 금지(저작권). 문체 참고 자료는 본문에 인용하지 않는다.

## 5. 완료 기준

모두 만족해야 완료다.

- 모든 범주에 2건 이상
- [1차] 비중이 전체 인용의 60% 이상
- 작품의 핵심 사실 범주(조사 범위 표에 ★ 표시한 1~2개)는 3건 이상
- `characters` 중 직업이 있는 인물 모두 직군 자료 1건 이상
- "미해결 항목"에 남은 충돌·공백이 적혀 있음

완료하면 원장에 `stage: research done <날짜>`를 남기고 "write 단계로 장면 설계와 초안을 시작하세요"라고 안내한다.
